Trip Advisor Clone

A beginner-friendly TripAdvisor-inspired travel homepage built with HTML and CSS.

## Features

- Responsive navigation bar
- Travel search bar and category tabs
- Travel inspiration, experience, and destination cards
- Promotional banner and contact form layout
- CSS hover effects and mobile-friendly layouts

## Built With

- HTML5
- CSS3

## Run the Project

Download or clone the repository, then open `index.html` in a web browser. No installation is needed.
https://abdulrahman077.github.io/Trip-Advisor-clone/ 

## Project Notes

This is a static course project. Search, category tabs, Ask AI, Sign In, and the contact form are visual elements; they do not submit data or perform searches yet. The project does not use JavaScript.

Some travel photos and fonts are loaded from external websites, so an internet connection is needed to show them. The TripAdvisor-style logo image is stored in the `images` folder.

This project is for learning and practice. It is inspired by Tripadvisor and is not affiliated with Tripadvisor.
